# 口コミ返信生成モジュール 活用マニュアル

MEO自動化ツール（試作）の **「口コミ返信生成」** 機能の使い方をまとめたマニュアルです。
Googleビジネスプロフィール（以下 GBP）の口コミへの返信文を、AIで複数案作成します。
**ネガティブな口コミを自動判定し、担当者へのエスカレーションを促す**のが大きな特徴です。

---

## 1. このツールでできること / できないこと

### できること

- 口コミ本文と星評価を入力すると、**返信文を2〜4案、一度に自動生成**
- 口コミの **感情（ポジティブ／中立／ネガティブ）を自動判定**
- 低評価・不満を含む口コミは **「🚨 担当者の確認を推奨」警告を自動表示**（エスカレーション）
- 星評価・トーンに応じて文面を最適化（高評価＝感謝中心／低評価＝謝意とオフライン誘導）
- 返信文は画面上で編集 → ワンクリックでコピー

### まだできないこと（試作の範囲外）

- GBPからの **口コミの自動取得**（→ GBP公式API連携で将来対応可能）
- GBPへの **返信の自動投稿**（→ 同上）
- 口コミ件数の集計・推移管理

> 返信文の「生成」と「ネガ判定」を自動化し、確認と投稿は人が行う **半自動** 設計です。
> 公開される返信での炎上・不適切対応を防ぐための、意図的な線引きです。

---

## 2. 起動方法

第1弾モジュールと同じアプリ内にあります。

```bash
npm install   # 初回のみ
npm run dev
```

ブラウザで **http://localhost:3000/reviews** を開く（または上部ナビの「口コミ返信」）。
APIキー未設定でも **サンプル生成モード** で動作します（本生成への切替は投稿文生成マニュアル第5章と共通）。

---

## 3. 画面の使い方

### 入力項目

| 項目 | 必須 | 説明 | 入力例 |
|---|:--:|---|---|
| 店舗名 | ● | 対象店舗名 | 月読 渋谷店 |
| 業種 | ● | 業態 | リラクゼーション |
| 星評価 | ● | 口コミの評価（★で選択） | ★★（2） |
| 口コミ本文 | ● | 受け取った口コミの全文 | 施術はよかったが20分待たされた… |
| 投稿者名 | － | 表示名（任意） | 田中 |
| 返信トーン | ● | 誠実・丁寧／あたたかい／フォーマル | 誠実・丁寧 |
| 生成する案の数 | ● | 2〜4案 | 3案 |

### 操作

1. 店舗名・業種・口コミ本文を入力（星評価はクリックで選択）。
2. **「💬 返信文を生成する」** をクリック。
3. 右側に感情バッジ・（必要時）エスカレーション警告・返信案が表示されます。

---

## 4. 感情判定とエスカレーション

生成結果の上部に表示されます。

| 表示 | 意味 |
|---|---|
| 😊 ポジティブ | 高評価・好意的な内容 |
| 😐 中立 | どちらともいえない内容 |
| ⚠️ ネガティブ | 低評価・不満・トラブルを含む |

ネガティブ判定時は **🚨「担当者の確認を推奨します」** バナーが出ます。
この場合、AIの返信案をそのまま投稿せず、**まず事実関係を社内で確認**してください。

> 判定基準（サンプルモード時）：星2以下、または不満を示す語句を含む場合にネガティブ＋エスカレーション。
> 本生成（Claude）時は、文脈までふまえてより精緻に判定します。

---

## 5. 返信文の使い方

各カード：返信本文（編集可）＋文字数＋「返信文をコピー」ボタン。

### GBPへの返信手順（手動）

1. 案を選び、必要に応じて編集（**個人情報・予約内容は書かない**）。
2. 「返信文をコピー」。
3. [GBPマネージャ](https://business.google.com/) → 対象店舗 → クチコミ → 該当の口コミ → 「返信」に貼り付けて送信。

> 補足：2026年4月以降、API経由の返信は審査（承認/却下）を通る仕様になりました。
> マネージャ画面からの手動返信は従来どおりです。

---

## 6. 運用上の注意（重要）

- **ネガティブ口コミは即返信しない**：エスカレーション警告が出たら、必ず担当者・店舗と事実確認。
- **公開前提**：返信は全ユーザーに見えます。感情的・防御的な表現は避ける（プロンプト側でも抑制）。
- **個人情報を書かない**：来店日時・施術内容・病状など、本人特定につながる情報は返信に含めない。
- **事実確認**：AIは口コミの背景を知りません。謝罪・約束の内容は実態と齟齬がないか確認。

## 7. よくある質問

**Q. 低評価でも自動で返信させられますか？**
A. 試作では「生成」までです。ネガティブは警告を出し、人の確認を挟む設計にしています。安全のための意図的な仕様です。

**Q. 同じ評価だと案が似ます。**
A. トーンを変える、投稿者名を入れる、口コミ本文を具体的にすると差が出ます。本生成（Claude）にするとさらに多様になります。

**Q. ポジティブな口コミにも返信すべき？**
A. はい。返信率は信頼感に寄与します。本モジュールで感謝の返信を素早く量産できます。
