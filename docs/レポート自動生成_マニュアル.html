1

このツールでできること / できないこと

✅ できること

  • 店舗・対象月を指定すると、主要指標を集計して月次レポートを自動生成
  • KPIを前月比つきカードで表示（表示回数・クリック・通話・ルート検索・口コミ・評価）
  • 直近6か月の表示回数推移を棒グラフで可視化
  • AIが講評を自動作成（総括／良かった点／課題／次月の改善提案）
  • レポート全文をワンクリックでコピー、ブラウザの印刷→PDF保存にも対応

🚧 まだできないこと（試作の範囲外）

  • 実GBPデータの取得（API連携が必要）
  • 複数店舗の一括レポート
  • スライド（PowerPoint等）への自動書き出し
    （テキストコピー＋印刷PDFで代替）
⚠️ 重要：現在のデータについて

試作版のデータは「サンプル（自動生成）」です。 店舗名＋対象月から決定的に生成しており、実際のGBPの数値ではありません。

同じ店舗名・月を入力すれば毎回同じ数値が出ます（デモ用）。実データにするには GBP Performance API / Reviews API との連携が必要です（第6章）。

2

起動方法

# 初回のみ
npm install

# 開発サーバー起動
npm run dev

ブラウザで http://localhost:3000/reports（または上部ナビ「レポート」）を開きます。

  1. ヘッダー：店舗名・対象月・データ出所・講評の生成元（AI/サンプル）
  2. 主要指標（前月比）：KPIカード（▲増加＝緑／▼減少＝赤）
  3. 表示回数の推移：直近6か月の棒グラフ（最新月はオレンジ）
  4. 講評：総括＋👍良かった点／⚠️課題／💡改善提案

4

レポートの活用

📨 クライアント共有

「レポート全文をコピー」→ メール・チャット・ドキュメントに貼り付け。

📄 PDF化

「印刷 / PDF保存」→ ブラウザの印刷ダイアログで「PDFに保存」を選択。

🗂 定例会資料

コピーしたテキストをスライドのメモ欄や台本に転記。

5

AI講評の品質を上げる

APIキー未設定時は、指標から組み立てたテンプレート講評（サンプル）になります。Claudeによる講評にすると、データの文脈をふまえたより自然で具体的な講評になります。

.env.local に設定（投稿文生成マニュアル第5章と共通）：

AI_GATEWAY_API_KEY=あなたのキー
MEO_GENERATION_MODEL=anthropic/claude-sonnet-4-6
💡 確認方法

ヘッダーの「講評: AI（…）」表示で、本生成（Claude）かサンプルかを確認できます。

6

実データ連携への発展

試作では lib/report-data.ts がサンプル数値を返しています。ここを以下のAPI取得に差し替えると、実データのレポートになります。

データ取得元API取得できる主な指標
表示回数・クリック・通話・ルート検索Business Profile Performance API各種パフォーマンス指標
口コミ件数・平均評価Reviews APIレビュー一覧・評価
📌 必要なもの

GBP API利用申請（審査・承認制）＋対象店舗の管理権限。

検索順位は公式APIに無いため、順位管理は別モジュール（外部手段）で扱います。

7

よくある質問

数値が実際のGBPと違います。
試作版はサンプルデータです（デモ用）。実データは第6章のAPI連携後に反映されます。
毎回数値が変わりませんが？
仕様です。店舗名＋月をシードに決定的生成しているため、デモの再現性があります。
レポートのデザインは変えられますか？
印刷PDFは画面レイアウトに準じます。体裁の要望があれば調整します。
