# 投稿文生成モジュール 活用マニュアル

MEO自動化ツール（試作）の **「投稿文生成」** 機能の使い方をまとめたマニュアルです。
Googleビジネスプロフィール（以下 GBP）のローカル投稿の本文を、AIで複数案まとめて作成します。

---

## 1. このツールでできること / できないこと

### できること（今回の試作の範囲）

- 店舗情報と投稿テーマを入力すると、**投稿本文を2〜5案、一度に自動生成**
- 案ごとに **切り口（訴求軸）を変える**ので、テンプレ感を避けられる
- **ハッシュタグ案・CTA（行動喚起）案**も同時に生成
- 生成された本文は **画面上でそのまま編集**でき、文字数もリアルタイム表示
- 「本文＋タグをコピー」で **クリップボードにコピー → GBPに貼り付け**

### まだできないこと（今回の試作の範囲外）

- GBPへの **自動投稿・予約投稿**（→ GBP公式API連携で将来対応可能。第6章参照）
- 画像の生成・添付
- 投稿実績の管理・カレンダー表示

> 投稿文の「生成」までを自動化し、最終チェックと投稿は人が行う **半自動** の設計です。
> これは事実誤り（日時・価格など）や薬機法・GBPガイドライン違反を防ぐための、意図的な線引きです。

---

## 2. 起動方法（開発環境）

### 前提
- Node.js 20以上（推奨：24）

### 手順

```bash
# プロジェクトフォルダで
npm install      # 初回のみ
npm run dev      # 開発サーバー起動
```

ブラウザで **http://localhost:3000** を開きます。

> APIキーを設定しなくても **「サンプル生成（モックモード）」** で全画面・全操作を試せます。
> 本物のClaude生成に切り替える方法は第5章を参照してください。

---

## 3. 画面の使い方

### 入力項目

| 項目 | 必須 | 説明 | 入力例 |
|---|:--:|---|---|
| 店舗名 | ● | 投稿する店舗の正式名称 | リラクゼーションサロン 月読 渋谷店 |
| 業種・カテゴリ | ● | GBPのカテゴリや業態 | リラクゼーション・もみほぐし |
| 投稿テーマ | ● | 今回の投稿で伝えたい主題 | 梅雨の疲れに効く45分コース新登場 |
| 強調したい訴求ポイント | － | 価格・特典・アクセスなど具体情報 | 初回限定2,980円／指名予約OK／駅徒歩3分 |
| 投稿タイプ | ● | 最新情報／特典・キャンペーン／イベント | 最新情報 |
| トーン | ● | 文章の雰囲気（4種） | 親しみやすい |
| 文字数の目安 | ● | 短め〜長め | 標準（〜250字） |
| 生成する案の数 | ● | 2〜5案 | 3案 |

### 操作

1. 必須項目（店舗名・業種・投稿テーマ）を入力すると、生成ボタンが押せるようになります。
2. **「✨ 投稿文を生成する」** をクリック。
3. 右側に投稿案がカードで並びます。

---

## 4. 生成結果の使い方

各カードには次が表示されます。

- **本文**（編集可能なテキストエリア）
- **文字数 / 目安**（目安超過時は赤字で警告）
- **ハッシュタグ案**（チップ表示）
- **CTA**（行動喚起の1文）
- **「本文＋タグをコピー」** ボタン

### GBPへの投稿手順（手動）

1. 気に入った案を、必要に応じて画面上で編集する。
   - **日時・価格・在庫・キャンペーン期間は必ず実情と照合**してください。
2. 「本文＋タグをコピー」をクリック。
3. [Googleビジネスプロフィール マネージャ](https://business.google.com/) を開く。
4. 対象店舗 →「最新情報を追加」→ 投稿タイプを選択。
5. 本文を貼り付け、写真・ボタン（予約/電話/リンク）を設定して投稿。

## 5. 本物のAI生成（Claude）を有効にする

APIキー未設定時は、入力値を差し込んだ簡易サンプル（モック）が返ります。
**Claudeによる本生成** に切り替えるには、環境変数を設定します。

### 手順

プロジェクト直下に **`.env.local`** を作成し、以下を記載します。

```bash
# Vercel AI Gateway のキー（https://vercel.com/docs/ai-gateway で発行）
AI_GATEWAY_API_KEY=あなたのキー

# 使用モデル（省略時は anthropic/claude-sonnet-4-6）
MEO_GENERATION_MODEL=anthropic/claude-sonnet-4-6
```

設定後、開発サーバーを再起動（`Ctrl+C` → `npm run dev`）すると、
生成結果の右上バッジが **「● AI生成」** に変わります。

### モデルの選び方

| モデル | 特徴 | 向き |
|---|---|---|
| `anthropic/claude-haiku-4-5` | 高速・低コスト | 大量投稿、ドラフト量産 |
| `anthropic/claude-sonnet-4-6` | バランス（既定） | 通常運用 |
| `anthropic/claude-opus-4-8` | 最高品質 | 重要店舗・最終案 |

> AI生成が失敗した場合も、UIを止めないよう自動でサンプル生成にフォールバックします。

---

## 6. 運用上の注意（重要）

- **事実確認は人間の責任**：価格・日時・コース内容などはAIが誤る可能性があります。投稿前に必ず確認。
- **薬機法・景表法**：「治る」「効果は確実」等の断定や、根拠のない最上級表現は使わない（プロンプト側でも抑制していますが最終確認を）。
- **GBPガイドライン**：本文に電話番号・URLを直書きしない（ボタン機能を使う）。投稿は最大1500字。
- **個人情報**：口コミ投稿者名など個人を特定する情報は入力しない。

## 7. よくある質問

**Q. APIキーがなくても使えますか？**
A. はい。サンプル生成モードで画面・操作はすべて試せます。文章品質を上げたいときにキーを設定してください。

**Q. 生成した文章の著作権・責任は？**
A. 最終的な投稿内容の責任は運用担当者にあります。本ツールは下書き作成の支援です。

**Q. 案がどれも似てしまう。**
A. 「強調したい訴求ポイント」を具体的に書くほど差が出ます。トーンや投稿タイプを変えての再生成も有効です。

## 8. 今後の拡張（ロードマップ）

この投稿文生成は、MEO自動化ツールの最初のモジュールです。GBP公式APIと連携することで、次が実現可能です。

| 拡張 | 必要なもの | 実現可否 |
|---|---|---|
| GBPへの予約投稿まで自動化 | GBP API利用申請＋店舗の管理権限 | ◎ 可能 |
| 投稿実績の自動取得・カレンダー管理 | 同上 | ◎ 可能 |
| 口コミ返信文生成モジュール | Claude（本ツールと同方式） | ◎ 可能 |
| レポート自動生成（アクセス数・口コミ） | GBP Performance API | ◎ 可能 |
| 検索順位の取得 | 公式API外（スクレイピング/外部ツール） | △ 要検討 |

> 詳細な可否は別途整理済みです。次に作るモジュールを決めて、1つずつ追加していきます。
